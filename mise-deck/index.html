MiseDeck

mise 的命令行，长成一个桌面应用。 The mise CLI, as a desktop app.

八个页面，每个对应 CLI 的一部分。安装、切换、升级、写入环境变量——每一步都真的执行一条 mise 命令，命令行、日志与退出码原样留在执行面板里。 Eight pages, each one a part of the CLI. Install, switch, upgrade, write an env var — every step runs a real mise command, and the panel keeps the argv, the logs, and the exit code exactly as they were.

FAQ

常见问题。 Questions.

MiseDeck 和 mise 是什么关系？ How is MiseDeck related to mise?

MiseDeck 是独立的社区项目，与 mise 及其维护者没有隶属关系。它只是给 mise 的命令行套了一层图形界面：界面里的每个动作，底层都是一条真实的 mise 命令。 MiseDeck is an independent community project, not affiliated with mise or its maintainer. It is a graphical layer over the mise CLI: every action in the UI is a real mise command underneath.

会捆绑 mise 吗？ Does it bundle mise?

不会。MiseDeck 调用你机器上的 mise，需要 mise ≥ 2025.12.5。如果没装，首页会给出引导安装。 No. MiseDeck calls the mise on your machine and needs mise ≥ 2025.12.5. If it is missing, the Home page offers a guided install.

支持哪些平台？ Which platforms are supported?

macOS（Apple Silicon）打磨完成；Windows x64 能跑，已在真实机器上走通，安装包也已实测安装；Linux 提供 deb / rpm / AppImage，但尚未在真实桌面环境验证。 macOS on Apple Silicon is polished. Windows x64 runs and has been exercised end-to-end on real hardware, including the installer. Linux ships deb / rpm / AppImage but is not yet verified on a real desktop.

macOS 上打不开怎么办？ macOS says the app is damaged — now what?

那是 Gatekeeper 的隔离标记，不是文件损坏。执行 xattr -dr com.apple.quarantine /Applications/MiseDeck.app 即可；也可以在「系统设置 → 隐私与安全性」里点「仍要打开」。 That is Gatekeeper's quarantine flag, not a corrupted download. Run xattr -dr com.apple.quarantine /Applications/MiseDeck.app, or use System Settings → Privacy & Security → Open Anyway.

我的数据会离开本机吗？ Does any of my data leave the machine?

不会。MiseDeck 没有账号、没有遥测，所有读取与写入都发生在本机，通过 mise 命令完成。对外请求只有两个，都是版本检查：手动触发的「检查 MiseDeck 更新」，以及启动十秒后的静默检查（最多一天一次）。两者读的是同一份 release feed——MiseDeck 不会下载或安装任何构建，发现新版本时只会指向它的发布页。 No. MiseDeck has no account and no telemetry; every read and write happens locally, through mise. Two outbound requests exist, and both are version checks: the manual Check for MiseDeck updates, and a silent check ten seconds after launch (at most once a day). Both read the same releases feed — MiseDeck never downloads or installs a build; a newer version only ever points at its Release page.

能和 mise CLI 一起用吗？ Can I keep using the mise CLI alongside it?

可以，两者操作的是同一份配置。你在终端里 mise use 过的版本，MiseDeck 里立刻能看到；反过来也一样。 Yes — both act on the same configuration files. A version you use in the terminal shows up in MiseDeck immediately, and the other way round works too.
